# Mockup renders

Reference images of the app mockup as of artifact Version 41 (2026-10-28), 1440 px wide, one per screen:
`1-first-run-setup.png`, `2-live-draft.png`, `3-available-players.png`, `4-draft-board.png`, `5-settings.png`.

They were made with headless Edge, using a small stand-in for the Design Canvas runtime (it expands the `sc-for`, `sc-if` and `{{ }}` tags), not with the real
renderer, so spacing may differ slightly from the published artifact. Hover boxes ("?" explainers and tag explanations) and the collapsed bench and
developer-options rows are not shown open. The image only needs regenerating when the screens change.
